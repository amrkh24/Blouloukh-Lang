# 🚀 لغة البلولوخ v0.8 - إصدار المحرك الاحترافي
**الإصدار الرسمي والنهائي: "حاسب يا أسطى وعلي وضعك"**

مرحباً بك في تحديث **v0.8**. تم نقل اللغة بالكامل وتحديثها لتعمل بمحرك **C#** قوي مع تطبيق **Recursive Descent Parser** حقيقي لفهم ترتيب العمليات الحسابية والأقواس تلقائياً!

### 🌟 المميزات الجديدة في إصدار v0.8:
1. **أولوية العمليات الرياضية:** المحرك يفهم الآن تلقائياً أن الضرب والقسمة (`*`, `/`) يسبقان الجمع والطرح (`+`, `-`).
2. **دعم الأقواس `( )`:** تتيح للمستخدم التحكم الكامل في أولوية الحساب مثل: `ياض س = (10 + 5) * 2`.
3. **دعم المدخلات الحية `هاتلي`:** تتيح استقبال أرقام مباشرة من الكونسول أثناء التشغيل.

---

### 📂 هيكل ملفات المشروع الجديد (C#):
المشروع أصبح يحتوي على ملفات المحرك الاحترافي داخل المجلد لجعل اللغة بمستوى اللغات الاحترافية:
* `TokenType.cs` : لتحديد أنواع الرموز الجديدة (الأقواس والمدخلات).
* `Token.cs` : لتخزين بيانات الرموز المكتشفة.
* `Lexer.cs` : ماسح الأكواد الذكي.
* `Parser.cs` : القلب النابض للغة (Recursive Descent Parser).
* `Program.cs` : ملف التشغيل والاختبار الأساسي في الـ Visual Studio.

---

### 💻 طريقة التجربة والتشغيل:
1. **في المتصفح مباشرة:** افتح ملف `index.html` لتجربة المحاكي المحدث لايف مباشرة من أي مكان وبنفس الشكل القديم!
2. **باستخدام Visual Studio:** افتح المشروع وقم بتشغيل ملف `Program.cs` للاستمتاع بأعلى أداء للمحرك الجديد.
