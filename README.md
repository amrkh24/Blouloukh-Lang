# 🚀 لغة البلولوخ v0.2
**الإصدار الرسمي: "حاسب يا أسطى"**

### الكلمات المحجوزة ومعانيها البرمجية:
* **ثبّت حضور**: لتعريف المتغيرات (`var`).
* **حاسب**: جملة الشرط (`if`).
* **سكّة تانية**: الشرط البديل (`else`).
* **طب افرض**: شرط إضافي (`else if`).
* **وعلى وضعك**: حلقة التكرار (`while`).
* **لفّ وارجع تاني**: حلقة التكرار (`for`).
* **سمّعنا**: للطباعة على الشاشة (`print`).
* **انزل بالجديد**: بداية البلوك كود `{`.
* **خلّص الكلام**: نهاية البلوك كود `}`.
